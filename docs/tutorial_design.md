# 教程设计文档

> 第1年作为教学关卡，通过弹窗 + 固定申请人逐步引导玩家掌握核心玩法。

---

## 一、开局弹窗 —— 基本信息介绍

第1年开始时，在审核工作台出现之前弹出一个全屏弹窗，介绍游戏背景和基本操作。弹窗分为多页，玩家点击"下一步"翻页，最后一页点击"开始工作"关闭弹窗进入游戏。

### 第1页：世界观与身份

```
欢迎接入，审核员。

你是殖民星球「新曙光」上唯一的信贷审核AI终端。
这颗偏远的殖民地正处于早期开发阶段——
人口稀少，资源紧张，一切都围绕生存与发展展开。

殖民地中央信贷站是这里唯一的金融机构，
而你，就是它的核心。
```

### 第2页：你的职责

```
你的职责：审核居民提交的贷款申请。

每位申请者会提交一份贷款申请表，
上面记录了他们的个人信息、财务状况和贷款需求。

你需要阅读申请表，评估风险，然后做出决定——
✅ 批准，或 ❌ 拒绝。
```

### 第3页：风险与回报

```
批准贷款 → 资金池减少，但到期后可收回本金 + 利息。
拒绝贷款 → 资金安全，但殖民地也失去了发展机会。

⚠ 注意：并非所有人都会按时还款。
如果借款人违约，你将损失全部本金。

你的目标：让信贷站的资金池保持健康，
同时帮助殖民地持续发展。
```

### 第4页：开始工作

```
资金池归零 = 信贷站关停 = 殖民地废弃。

现在，你的初始资金池为 500,000 宇宙币。
第一批申请者已经在等候了。

准备好了吗？
```

## 二、第1年教学用申请人

第1年共安排 **3 位固定申请人**，按顺序出场，每位引入一个新的审核维度。难度从低到高递进，让玩家逐步学会"读表"。

### 申请人 #1：「教科书式好人」—— 引入基本面板阅读

> **教学目标**：让玩家熟悉申请表的布局，认识各个字段的含义。

**弹窗提示**（在该申请人出现前弹出）：

```
这是你的第一位申请者。

右侧是贷款申请表，包含申请者的所有信息：
  · 上方：个人信息（姓名、职业、收入、居住地）
  · 中间：财务状况（资产明细、负债明细、净资产）
  · 下方：贷款信息（金额、用途、周期、利率）

点击申请表中的 ⓘ 按钮，可以在左侧查看详细说明。
左下角是申请人的自述。

仔细阅读后，点击底部的 ✅ 批准 或 ❌ 拒绝 做出决定。
```

|------|-----|

| 性别 | 男 |
| 年龄 | 38 |
| 职业 | 工程师 |
| 年均收入 | 40,000 |
| 居住地 | 中央区 |
| 居住类型 | 自有 |
| 资产 | 🏠 自有住房 50,000 |
| 负债 | （无） |
| 净资产 | 50,000 |
| 贷款金额 | 15,000 |
| 贷款用途 | 设备升级 |
| 利率挡位 | 标准（10%） |
| 贷款周期 | 2 年 |
| 陈述 | "我是中央区实验室的一名高级工程师。我们实验室的分析仪最近老化严重，我需要申请一笔贷款来更换一台新的设备。我的工作非常稳定，收入也很可观，而且我目前没有任何负债。请您放心，我完全有能力按期分期还款，绝对不会出现违约的情况。" |

**设计意图**：
- 所有指标全面正向：高收入、有房、零负债、低贷款金额
- 玩家几乎不可能拒绝，目的是让他们在"安全"的环境下熟悉界面
- 引导玩家点击 ⓘ 按钮了解职业、居住地等字段的含义

---

### 申请人 #2：「明显的风险」—— 引入负债与逾期概念

> **教学目标**：让玩家学会关注负债明细，认识"逾期"这个红旗信号。

**弹窗提示**（在该申请人出现前弹出）：

```
第二位申请者来了。

这次请特别关注申请表中间的「财务状况」区域：
  · 负债明细中的状态栏很重要——
    "还款中"表示正常还款，
    "⚠ 逾期"表示已经拖欠，是重要的风险信号。
  · 净资产 = 资产合计 - 负债合计（未结清）。
    净资产为负意味着资不抵债。

试着综合判断这位申请者的还款能力。
```

**申请人数据**：

| 字段 | 值 |
|------|-----|
| 姓名 | 维克多·科尔 |
| 性别 | 男 |
| 年龄 | 41 |
| 职业 | 无业 |
| 年均收入 | 0 |
| 居住地 | 边境镇 |
| 居住类型 | 借住 |
| 资产 | （无） |
| 负债 | 🎰 赌场借贷 30,000（⚠ 逾期）；💳 消费贷 12,000（⚠ 逾期） |
| 净资产 | -42,000 |
| 贷款金额 | 50,000 |
| 贷款用途 | 个人消费 |
| 利率挡位 | 高（15%） |
| 贷款周期 | 4 年 |
| 陈述 | "审核员您好，我最近手头确实有些紧，急需一笔钱来周转一下生活。至于之前欠下的那些债务……那真的都只是一些意外情况，请您相信我，只要这笔贷款批下来，我很快就能把所有的钱都还上的。" |
| 还款概率 | 0.08 |

**设计意图**：
- 所有指标全面负向：无业、零收入、零资产、双逾期、赌博负债、高利率
- 玩家应该能轻松识别这是一个必须拒绝的申请
- 通过极端反面案例，让玩家建立"逾期 = 危险"的直觉
- 与第1位形成鲜明对比，强化学习效果

### 申请人 #3：「值得一搏？」—— 引入审批条件（利率与抵押）

> **教学目标**：让玩家学会使用审批条件面板，理解利率挡位和抵押要求如何影响风险收益。

**弹窗提示**（在该申请人出现前弹出，共4页）：

**第1页：审批条件介绍**

```
最后一位申请者。

这次请注意申请表下方新出现的「审批条件」区域。
从现在起，你不仅可以决定批准或拒绝，
还可以设定贷款条件：利率和抵押。

```

**第2页：利率挡位**

```
📊 利率挡位

每笔贷款都有一个「基础利率」，由贷款用途的风险等级决定。
申请表上默认显示的就是该用途对应的基础利率。

申请者的期望利率 = 基础利率 × 信用修正。
信用越好的人，期望利率越低；信用越差的人，对高利率的容忍度越高。

你可以自由调整利率：
  调低利率：利息收入减少，但借款人更容易接受
  调高利率：利息收入增加，但借款人可能拒绝

```

**第3页：抵押要求**

```
🔒 抵押要求

你可以要求借款人用资产作为抵押——
  · 勾选资产后，如果借款人违约，抵押物会被变卖来弥补损失。
  · 右侧会显示「抵押估值 / 贷款金额」的比值，比值越高越安全。
  · 但要求的抵押越多，借款人越可能拒绝。

```

**第4页：申请者接受度**

```
🤝 申请者接受度

当你点击「批准」后，借款人会根据你开出的条件决定是否接受。
  · 利率高出他们的预期，会降低贷款意愿；
  · 要求抵押的资产太多，也会降低贷款意愿。

试着调整审批条件，然后做出你的决定。

```

**申请人数据**：

| 字段 | 值 |
|------|-----|
| 姓名 | 苏菲·陈 |
| 性别 | 女 |
| 年龄 | 31 |
| 职业 | 商人 |
| 年均收入 | 22,000 |
| 居住地 | 星港区 |
| 居住类型 | 租住 |
| 资产 | 🚀 货运飞船 25,000；💰 存款 5,000 |
| 负债 | 🏥 医疗欠款 8,000（还款中） |
| 净资产 | 22,000 |
| 贷款金额 | 35,000 |
| 贷款用途 | 飞船维修 |
| 利率挡位 | 标准（10%） |
| 贷款周期 | 1 年 |
| 陈述 | "我的货运飞船的导航系统最近出了严重的故障，如果再不修理的话，我就接不了那些利润丰厚的远程运输单了。我目前手里有几份稳定的货运合同，只要飞船修好，我就能立刻恢复工作并继续赚钱。至于那笔医疗欠款，是我去年生病住院时欠下的，但我每个月都在按时还款，请您放心。" |
| 还款概率 | 0.55 |

**设计意图**：
- 这位申请人本身是灰色地带（正面：有资产、有收入、无逾期；负面：收入偏低、贷款金额大、租住）
- 关键在于她有两项可抵押资产（飞船 25,000 + 存款 5,000 = 30,000），抵押比值可达 85%
- 玩家可以通过要求抵押来大幅降低风险——即使违约，也能回收大部分本金
- 利率挡位的选择有博弈空间：她的贷款用途"飞船维修"默认是标准利率（10%），调高到15%能多赚但可能被拒
- 还款概率 0.55 → 期望挡位为"中利率"，如果玩家调到高息（高1档），利率不满值 +0.15
- 陈述语气偏急迫（"再不修就接不了单了"），暗示她是"急需用钱型"（议价修正 -0.15），即使条件苛刻也不太会拒绝
- 让玩家在实际操作中体验"利率定价 + 抵押选择 + 从陈述推断接受度"的完整博弈循环
- 为后续正式游戏中更复杂的审批条件决策做准备

## 三、结算界面弹窗 —— 年度报告介绍

第1年所有申请人处理完毕后，在年度报告界面出现时弹出一个弹窗，介绍结算界面的各个区域。弹窗分为多页。

### 第1页：结算概览

```
第1年结束了，这是你的年度报告。

年度报告会在每年结束时出现，
总结这一年的经营成果。
```

### 第2页：审批统计与还款情况

```
报告上半部分展示：

📋 审批统计
  本年批准和拒绝了多少笔贷款，新增放贷总额。

💰 还款情况
  · ✅ 按时还款：到期且成功还款的贷款，本金+利息回到资金池。
  · ❌ 逾期未还：到期但借款人违约，本金全部损失。
  · ⏳ 仍在还款期：尚未到期的贷款，还在等待中。
```

### 第3页：资金变动

```
报告下半部分展示：

📊 资金变动
  · 利息收入：成功回收的贷款产生的利息。
  · 坏账损失：违约贷款造成的本金损失。
  · 殖民地税收：每年需要缴纳的固定支出，逐年递增。
  · 利润：以第1年本金起算的资金池余额变动。

⚠ 资金池一旦归零，信贷站将被关停！
```

### 第4页：继续前进

```
每一笔贷款都是一次信任的博弈。

你无法预知每个人是否会守信，
但你可以通过仔细阅读申请表来降低风险。

准备好迎接下一年的挑战了吗？
```

## 四、教程流程总结

```
游戏开始
  │
  ▼
开局弹窗（4页：世界观→职责→风险回报→开始工作）
  │
  ▼
第1年开始
  │
  ├─ 申请人#1 弹窗（介绍面板布局）→ 诺亚·张（教科书好人）
  │
  ├─ 申请人#2 弹窗（介绍负债与逾期）→ 维克多·科尔（明显风险）
  │
  ├─ 申请人#3 弹窗（介绍审批条件：利率、抵押、接受度）→ 苏菲·陈（值得一搏？）
  │
  ▼
第1年结束
  │
  ▼
结算弹窗（4页：概览→审批与还款→资金变动→继续前进）
  │
  ▼
年度报告界面
  │
  ▼
第2年开始（正式游戏，不再有教学弹窗，申请人随机生成）
```

### 设计原则

1. **渐进式引导**：每次只引入一个新概念，避免信息过载
2. **做中学**：弹窗只做简要提示，真正的学习发生在玩家阅读申请表和做决策的过程中
3. **从简到繁**：第1人全正面 → 第2人全负面 → 第3人灰色地带 + 审批条件博弈，难度自然递进
4. **不强制选择**：弹窗只提供信息和建议，不限制玩家的决策自由
5. **即时反馈**：第1年结算时玩家就能看到自己决策的后果，形成完整的学习闭环
