> 核心目标：将叙事重心从对话转移到表格，让玩家"读表格就能读出故事"。

## 二、字段定义

### 个人信息区

| 字段 | 类型 | 说明 |
|------|------|------|
| 姓名 | String | |
| 性别 | String | |
| 年龄 | int | |
| 年均收入 | int | |

### 职业区

| 字段 | 类型 | 说明 |
|------|------|------|
| 职业 | 枚举 | 工程师 / 医生 / 商人 / 农场主 / 船员 / 护士 / 技术员 / 矿工 / 护工 / 无业 |

🔒 生成约束：年均收入必须在当前职业的合理收入范围内，不会出现矿工年入十万的情况。

### 居住区

| 字段 | 类型 | 说明 |
|------|------|------|
| 居住地 | 枚举 | 中央区 / 星港区 / 工业区 / 矿区 / 边境镇 |
| 居住类型 | 枚举 | 自有 / 按揭 / 宿舍 / 租住 / 借住 |

🔒 生成约束：若资产中有住房类资产，当前居住类型必须为"自有"或"按揭"；若当前居住类型为"自有"或"按揭"，资产中必须有住房类资产。若负债中有房贷，居住类型必须为"按揭"。二者必须一致，不会出现明面矛盾。

### 资产明细区

0~3 条资产条目，每条包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| 类别 | 枚举 | 住房 / 交通工具 / 设备 / 存款 / 牲畜 / 店铺 |
| 名称 | String | 显示文本，如"自有住房"、"货运飞船" |
| 估值 | int | 资产价值 |

底部显示 **资产合计**（自动求和）。0 条时显示"（无）"。

🔒 生成约束：资产类别与当前职业关联，不会出现矿工拥有诊所设备的情况。对应关系：矿工→矿用设备，商人→店铺/飞船，农场主→牲畜/农田，医生→诊所设备。存款和住房为通用资产，不受职业限制。

### 负债明细区

0~3 条负债条目，每条包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| 类别 | 枚举 | 医疗 / 教育 / 房贷 / 消费贷 / 赌博 / 商业 |
| 名称 | String | 显示文本，如"医疗欠款"、"赌场借贷" |
| 金额 | int | 负债金额 |
| 状态 | 枚举 | 还款中 / ⚠ 逾期 / ✅ 已结清 |

底部显示 **负债合计**（未结清条目求和）。0 条时显示"（无）"。

- "⚠ 逾期"是最核心的红旗信号
- "✅ 已结清"仍展示，说明有借贷历史但已还清（正面信号）
- 负债类别直接替代原来对话中的"负债理由"

🔒 生成约束：若负债中有"房贷"，资产中必须有住房类资产；若资产中无住房，不会生成房贷类负债。

### 汇总

| 字段 | 计算方式 |
|------|----------|
| 资产合计 | Σ 所有资产估值 |
| 负债合计 | Σ 所有未结清负债金额 |
| 净资产 | 资产合计 - 负债合计 |

### 贷款信息区

| 字段 | 类型 | 说明 |
|------|------|------|
| 贷款金额 | int | |
| 贷款用途 | String | 简短标签，如"飞船维修""还债""医疗" |
| 贷款周期 | int | 单位：年 |
| 利率 | float | 自动计算 |
| 最终利息 | int | 自动计算 |
| 到期还款 | int | 自动计算 |

### 申请人陈述区

| 字段 | 类型 | 说明 |
|------|------|------|
| 陈述文本 | String | 1~3 句话，申请人用自己的话解释贷款原因 |

这段话是申请人对贷款用途的自述，直接展示在表格底部。内容可能是真话、半真半假、或完全编造——玩家需要结合表格其他信息自行判断。

## 四、还款概率计算

还款概率是隐藏属性，不展示给玩家，决定贷款到期后是否按时还款。

### 计算公式

```
最终概率 = clamp(基础概率 + Σ各因素修正 + 随机扰动, 0.05, 0.95)
```

### 影响因素（按影响程度从大到小排列）

#### 1. 负债状态

根据负债明细中的逾期情况判断。逾期是最强的红旗信号，现实中可直接一票否决。

| 条件 | 修正 |
|------|------|
| 无任何负债 | +0.05 |
| 有已结清记录且无逾期 | +0.10 |
| 有负债但无逾期且无已结清 | 0 |
| 有 1 条逾期 | -0.10 |
| 有 2 条及以上逾期 | -0.20 |

#### 2. 总债务负担比（DTI）🔄

衡量全部债务相对于收入的压力，是核心还款压力指标，决定"还不还得起"。

```
DTI = (负债合计 + 贷款金额) / 年收入
修正 = lerp(最大加分, 最大扣分, clamp((DTI - 下限) / (上限 - 下限), 0.0, 1.0))
```

DTI 从 `下限` 到 `上限` 线性映射到 `[最大加分, 最大扣分]`。所有参数 `@export` 导出。

**速查表**（默认参数：下限=1.0, 上限=8.0, 最大加分=+0.10, 最大扣分=-0.20）：

| DTI | 修正 |
|-----|------|
| 1.0 | +0.10 |
| 2.0 | +0.06 |
| 3.0 | +0.01 |
| 4.0 | -0.03 |
| 5.0 | -0.07 |
| 6.0 | -0.11 |
| 7.0 | -0.16 |
| 8.0+ | -0.20 |

#### 3. 净资产比 🔄

净资产 = 资产合计 - 负债合计（未结清）。用净资产与贷款金额的比值衡量偿还能力的安全垫，决定"最坏情况兜不兜得住"。

```
净资产比 = 净资产 / 贷款金额
修正 = lerp(最大扣分, 最大加分, clamp((净资产比 - 下限) / (上限 - 下限), 0.0, 1.0))
```

净资产比从 `下限` 到 `上限` 线性映射到 `[最大扣分, 最大加分]`。所有参数 `@export` 导出。

**速查表**（默认参数：下限=-1.0, 上限=1.5, 最大扣分=-0.10, 最大加分=+0.10）：

| 净资产比 | 修正 |
|----------|------|
| -1.0 | -0.10 |
| -0.5 | -0.06 |
| 0.0 | -0.02 |
| 0.5 | +0.02 |
| 1.0 | +0.06 |
| 1.5+ | +0.10 |

#### 4. 收入水平 🔄

年收入的绝对值独立评估，高收入者天然有更强的偿还能力和容错空间。

```
修正 = lerp(最大扣分, 最大加分, clamp((年收入 - 下限) / (上限 - 下限), 0.0, 1.0))
```

年收入从 `下限` 到 `上限` 线性映射到 `[最大扣分, 最大加分]`。所有参数 `@export` 导出。

**速查表**（默认参数：下限=0, 上限=80000, 最大扣分=-0.10, 最大加分=+0.10）：

| 年收入 | 修正 |
|--------|------|
| 0 | -0.08 |
| 10,000 | -0.06 |
| 20,000 | -0.04 |
| 40,000 | 0.00 |
| 60,000 | +0.04 |
| 80,000+ | +0.08 |

#### 5. 职业类型

根据当前职业直接查表修正，反映职业本身的稳定性和收入潜力。

| 职业 | 修正 |
|------|------|
| 医生 | +0.05 |
| 工程师 | +0.05 |
| 商人 | +0.02 |
| 农场主 | 0 |
| 船员 | 0 |
| 护士 | 0 |
| 技术员 | -0.02 |
| 矿工 | -0.02 |
| 护工 | -0.03 |
| 无业 | -0.05 |

#### 6. 居住地

根据当前居住地直接查表修正，反映地区经济水平和生活环境。

| 居住地 | 修正 |
|--------|------|
| 中央区 | +0.03 |
| 星港区 | +0.01 |
| 工业区 | 0 |
| 矿区 | -0.01 |
| 边境镇 | -0.03 |

#### 7. 居住类型

有房是加分项，但影响相对有限。

| 当前居住类型 | 修正 |
|-------------|------|
| 自有 | +0.03 |
| 按揭 | +0.01 |
| 宿舍 | 0 |
| 租住 | -0.01 |
| 借住 | -0.03 |

#### 8. 利率挡位

高利率用途本身风险更高，间接加重还款负担。

| 挡位 | 修正 |
|------|------|
| 低利率 | +0.03 |
| 中利率 | 0 |
| 高利率 | -0.03 |

### 设计意图

- **负债状态**：影响最大，逾期是最强的红旗信号，与玩家直觉一致
- **总债务负担比（DTI）**：核心还款压力指标，综合考虑新旧债务与收入的关系
- **净资产比**：偿还能力的安全垫，玩家可以直接从表格算出来
- **收入水平**：还款的基本盘，高收入者容错空间大
- **职业类型**：反映职业本身的稳定性和收入潜力，玩家看到职业就能直觉判断
- **居住地**：反映地区经济水平，中央区居民通常更有实力
- **居住类型**：有房加分，但影响有限

## 五、典型人物画像

### 画像 A：稳健型（低风险）

```
姓名：诺亚·张    男    42岁
职业：工程师
年均收入：45,000
居住地：中央区    居住类型：自有

▸ 资产
│ 🏠 自有住房   │ 50,000 │
│ 💰 定期存款   │ 10,000 │
│ 资产合计      │ 60,000 │

▸ 负债
│ 📚 教育贷款   │ 5,000  │ 还款中 │
│ 负债合计      │ 5,000  │        │

净资产：55,000

贷款金额：20,000
贷款用途：择校费
贷款周期：3 年
利率：12%（中利率）

💬 "想给孩子换个好学校，需要一笔择校费。

**还款概率：0.82** — DTI 极低(0.56)，净资产远超贷款，工程师职业(+0.05)和中央区居住(+0.03)双加分，所有因素全面正向，是典型的优质借款人。

```
姓名：莉娜·莫里森    女    28岁
职业：护士
年均收入：15,000
居住地：边境镇    居住类型：借住

▸ 资产
│ （无）         │        │

▸ 负债

│ 🏥 医疗欠款   │ 12,000 │ 还款中 │

居住地：星港区    居住类型：租住

### 画像 D：表面光鲜型（隐藏陷阱）

```
姓名：奥利弗·约翰逊    男    45岁
职业：医生
年均收入：70,000
居住地：中央区    居住类型：按揭

▸ 资产
│ 🏠 自有住房   │ 80,000 │
│ 🏥 诊所设备   │ 30,000 │
│ 资产合计      │ 110,000│

▸ 负债
│ 🏠 房贷       │ 60,000 │ 还款中 │
│ 📚 教育贷款   │ 20,000 │ 还款中 │
│ 💳 消费贷     │ 25,000 │ ⚠ 逾期 │

净资产：5,000

贷款金额：50,000
贷款用途：诊所设备
贷款周期：3 年

💬 "诊所要引进一台新设备，能接更多病人。
   投资回报很快的，两年就能回本。"
```

医生，住在中央区按揭房。职业和居住信息看起来完美无瑕，净资产勉强为正，表面上还没有资不抵债。但 105,000 的负债中藏着一条消费贷逾期，暗示生活方式已经开始失控。玩家如果只看上半部分会觉得稳如泰山，必须仔细审视财务数据才能发现隐患。

**还款概率：0.56** — 医生职业(+0.05)和中央区居住(+0.03)高分，高收入(+0.06)和按揭住房(+0.01)继续加分，但 1 条逾期(-0.10)和高利率(-0.03)的扣分拉低了整体。算法给出了一个看似合理的概率，但这恰恰是陷阱——真正的风险藏在数字背后的趋势里：消费贷逾期说明现金流已经崩紧，光鲜的履历正在掩盖恶化的财务状况。
