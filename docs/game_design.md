# 贷款审批模拟游戏 - 策划案

> GameJam 主题：信任

## 一句话概述

玩家扮演银行贷款审批员，面对形形色色的真实申请者，根据他们的财务状况和贷款需求做出风险判断——**你愿意信任谁？**

---

## 核心概念

每个贷款申请者的情况各不相同：收入水平、负债情况、贷款金额、还款周期、贷款用途……

玩家的核心挑战是：**在有限的信息下，评估风险，做出信任决策。**

- 批准一个高风险贷款 → 可能获得高额利息回报，也可能血本无归
- 拒绝一个看似危险的申请 → 安全了，但也许错过了一个会按时还款的好人

---

## 核心循环

接收贷款申请 → 阅读申请者资料 → 评估风险 → 决定（批准/拒绝/调整条件）→ 承受后果 → 下一位

每回合处理若干位申请者，每回合结束后结算：还款到账 / 仍未还款 / 已超出还款期限。

---

## 世界观

### 背景设定

人类殖民时代，玩家扮演的是一座偏远殖民星球上的 **信贷审核AI终端**。

这颗星球是一个仍处于早期开发阶段的殖民地。人口稀少，资源紧张，所有经济活动都围绕殖民地的生存与发展展开。殖民地的中央信贷站是唯一的金融机构，负责为居民提供贷款服务，而玩家就是这个信贷站的核心审核系统。

### 为什么是AI？

殖民地人力资源极度匮乏，无法配备专职的人类信贷审核员。玩家被部署在信贷站终端上，自主处理所有贷款申请。殖民地管理层只关心结果——资金池是否健康、殖民地是否在发展。

### 贷款的意义

在殖民地，贷款不只是金融行为，而是殖民地生存的命脉：

- **采矿设备贷款**：矿工需要资金购买或维修采矿装备
- **飞船维修贷款**：运输船损坏后急需修复以维持物资供应
- **农业开发贷款**：开垦新的种植区以养活不断增长的人口
- **医疗贷款**：殖民地医疗资源稀缺，大病治疗费用高昂
- **创业贷款**：有人想开设新的商铺或服务设施
- **消费贷款**：日常生活开支，购买生活物资

### 还款的不确定性

殖民地环境恶劣，还款的不确定性来自多种因素：

- 矿脉枯竭、设备故障导致收入中断
- 太空风暴影响运输和贸易
- 殖民地政策调整、物价波动
- 个人意外事故或健康问题

### 游戏结束条件

- **失败**：信贷站资金池归零，殖民地发展运行出现严重问题，导致信贷站被关停，殖民地废弃
- **通关**：所有剧情角色的叙事线完成，玩家完成了剧情"使命"，振兴了殖民地
- **通关后**：游戏进入无尽模式，玩家可以继续运营信贷站，挑战更高得分

## 时间线与数值节奏

### 时间框架

- 每回合 = **1 年**（殖民地纪年）
- 每年处理 **3~5 名**申请者
- 总申请量约 **70 次**

### 游戏阶段

游戏分为 **主线阶段**（约 20 年）和 **无尽阶段**。

### 贷款周期

贷款周期为 1~8 年，周期越长，利率乘数越高（每多 1 年，乘数 +0.1）：

| 周期 | 利率乘数 | 以标准档 10% 为例 |
|------|----------|--------------------|
| 1 年 | ×1.0 | 10% |
| 2 年 | ×1.1 | 11% |
| 3 年 | ×1.2 | 12% |
| 4 年 | ×1.3 | 13% |
| 5 年 | ×1.4 | 14% |
| 6 年 | ×1.5 | 15% |
| 7 年 | ×1.6 | 16% |
| 8 年 | ×1.7 | 17% |

实际利率 = 基础利率 × 周期乘数，最终利息 = 贷款金额 × 实际利率 × 周期

### 经济参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 货币单位 | **宇宙币** | 殖民地通用货币 |
| 居民年收入范围 | 10,000 ~ 60,000 | 根据不同职业有不同估算 |
| 贷款金额范围 | 5,000 ~ 300,000 | 根据用途和周期浮动 |
| 初始资金池 | 500,000 | 信贷站启动资金 |

### 年化利率（按用途）

利率按贷款用途分为三档，逻辑简单：殖民地越鼓励的用途，利率越低。

| 档位 | 年化利率 | 对应用途 | 逻辑 |
|------|----------|----------|------|
| 低息 | 5% | 农业开发、医疗 | 殖民地政策扶持的基础产业 |
| 标准 | 10% | 采矿设备、飞船维修 | 生产性投资，收益可预期 |
| 高息 | 15% | 创业、消费 | 无保障，高风险 |

### 剧情角色时间安排

- **5 个剧情角色**，每人出现 **2~5 次**，总计约 **15 次**剧情申请
- 剧情申请占总申请量约 **1/4**
- 第一个剧情角色在 **第 1 年** 出场
- 最后一个剧情角色的叙事线在 **第 16~18 年** 收束
- 同一角色两次出场间隔 **3~5 年**，体现人生变化

## 核心玩法

### 审批流程

1. 申请者来到柜台，提交贷款申请
2. 玩家查看申请材料，了解申请者的基本情况
3. 玩家根据材料信息，评估这笔贷款，决定批准还是拒绝
4. 进入下一位申请者

### 申请者资料

每位申请者的贷款申请会以数据面板的形式呈现在玩家的审核界面上，包含以下字段：

| 字段 | 内容示例 | 审核参考 |
|------|----------|----------|
| 基本信息 | 艾琳·沃克 女 34岁 | 基本身份信息 |
| 职业 | 商人 | 职业决定收入稳定性和水平 |
| 年均收入 | 18,000 | 还款能力的核心指标 |
| 现有负债 | 12,000 | 负债比过高 = 高风险 |
| 贷款金额 | 50,000 | 金额越大，风险敞口越大 |
| 贷款用途 | 飞船维修 | 用途决定利率档位（低息/标准/高息） |
| 贷款周期 | 5 年 | 短期 / 中期 / 长期 |
| 利率 | 14%（基础 10% × 周期乘数 1.4） | 系统根据用途和周期自动计算 |
| 最终利息 | 35,000（50,000 × 14% × 5年） | 到期需连本带息一次还清 |

玩家可以点击面板上的字段，向申请者发起询问，获取更多细节。

### 风险评估的核心维度

玩家需要综合考虑以下因素：

- **还款能力**：收入 vs 负债
- **贷款用途**：高息用途风险也高
- **贷款周期**：短期贷款风险低，长期贷款不确定性大

---

## 反馈与评价系统（初步）

### 银行维度
- **资产质量**：批准的贷款中，按时还款 vs 已逾期未还的比例
- **业务量**：处理了多少申请，批准了多少
- **利润**：利息收入 - 坏账损失

### 社会/道德维度
- 被批准/拒绝的申请者后来怎么样了？

## 申请者数据建模

### 全局常量（配置在申请者之外，所有申请者共用）

| 常量 | 值 | 说明 |
|------|-----|------|
| `INTEREST_RATE_LOW` | 5% | 低息档基础利率（农业开发、医疗） |
| `INTEREST_RATE_STANDARD` | 10% | 标准档基础利率（采矿设备、飞船维修） |
| `INTEREST_RATE_HIGH` | 15% | 高息档基础利率（创业、消费） |
| `PERIOD_MULTIPLIER_FORMULA` | 1.0 + (周期-1) × 0.1 | 周期乘数公式 |
| `PURPOSE_TO_RATE_TIER` | 见利率表 | 用途 → 利率档位映射 |

### 个性化数据（配置在每位申请者身上）

| 字段 | 类型 | 示例 | 说明 |
|------|------|------|------|
| `name` | String | "艾琳·沃克" | 姓名 |
| `gender` | String | "女" | 性别 |
| `age` | int | 34 | 年龄 |
| `profession` | String | "商人" | 职业 |
| `annual_income` | int | 18000 | 年均收入 |
| `existing_debt` | int | 12000 | 现有负债 |
| `loan_amount` | int | 50000 | 贷款金额 |
| `loan_purpose` | String | "飞船维修" | 贷款用途 |
| `base_rate` | Enum | 标准利息 | 按照用途划分的利率 |
| `loan_period` | int | 5 | 贷款周期（1~8年） |
| `is_story_character` | bool | false | 是否为剧情角色 |
| `repay_probability` | float | 0.7 | 还款概率（暂由策划手动配置） |

### 计算值（运行时由系统自动算出，无需配置）

| 字段 | 公式 | 示例 | 说明 |
|------|------|------|------|
| `base_rate` | 由 `loan_purpose` 查利率表 | 10% | 基础利率 |
| `period_multiplier` | `1.0 + (loan_period - 1) × 0.1` | ×1.4 | 周期乘数 |
| `actual_rate` | `base_rate × period_multiplier` | 14% | 实际年化利率 |
| `total_interest` | `loan_amount × actual_rate × loan_period` | 35,000 | 最终利息 |
| `total_repayment` | `loan_amount + total_interest` | 85,000 | 到期还款总额 |
| `debt_ratio` | `existing_debt / annual_income` | 0.67 | 负债比（风险参考） |

## 界面设计

游戏界面围绕核心循环设计，总共只有 3 个核心界面 + 模板已有的通用界面（开始、暂停、设置）。

#### 布局分区

| 区域 | 内容 | 交互方式 |
|------|------|----------|
| 顶部状态栏 | 当前年份、当前第几位申请者（如 2/4） | 纯展示 |
| 左上 - 申请者形象 | 申请者头像或剪影 | 纯展示 |
| 左下 - 对话区域 | 申请者的口头回应 | 点击申请表字段后，此处显示回应文本 |
| 右侧 - 申请表面板 | 所有申请者数据字段 | 带 ⓘ 标记的字段可点击，触发询问 |
| 底部 - 操作区 | 批准 / 拒绝按钮 | 点击做出最终决策 |
| 底部状态栏 | 资金池余额、在贷总额、收益率 | 纯展示 |

#### 核心交互：询问机制

1. 玩家点击申请表上带 **ⓘ** 标记的字段
2. 左侧对话区域弹出申请者的口头回应（一段简短对话文本）
3. 回应内容可能透露额外信息，也可能模棱两可
4. 玩家可以自由询问多个问题

### 游戏结束界面

资金池归零时显示失败结局，通关时显示正面结局。

```
┌─────────────────────────────────────────────┐
│                                             │
│  信贷站资金池归零，殖民地被迫废弃……            │
│                                             │
│  ── 你的审核生涯 ──                          │
│  运营年数：8 年                              │
│  批准贷款：32 笔                             │
│  总利息收入：245,000                         │
│  总坏账损失：380,000                         │
│                                             │
│  [ 重新开始 ]    [ 返回主菜单 ]               │
└─────────────────────────────────────────────┘
```

通关时替换为正面叙事 + 最终评价，并提供进入无尽模式的选项。

### 交互流程

```
开始界面 → 审核工作台
  ├→ 查看申请表 → 点击字段询问 → 对话区显示回应 → 继续查看或做决策
  ├→ 批准/拒绝 → 下一位申请者（如有）
  └→ 本年申请者处理完毕 → 年度结算界面
      ├→ 资金池归零 → 游戏结束界面（失败）
      ├→ 剧情线全部完成 → 游戏结束界面（通关）→ 无尽模式
      └→ 进入下一年 → 审核工作台
```

### 设计要点

- **界面数量少**：核心只有 3 个界面（工作台、结算、结束），加上模板已有的开始/暂停/设置
- **交互极简**：主要操作就是"点字段问问题"和"批准/拒绝"，上手零门槛
- **信息层次清晰**：申请表是核心信息源，底部状态栏是全局概览，对话区是补充信息
- **叙事融入UI**：对话区和年度结算的"近况"让数字审批有了人情味，呼应"信任"主题
